# 礼品操作菜单遮挡紧急修复验收

## 问题与根因

- 生产后台礼品管理中，点击卡片右侧三点后，操作菜单被卡片遮挡，只露出菜单边框，按钮不可操作。
- 菜单虽然使用绝对定位和 `z-index`，但礼品卡片与外层 `audit-panel` 同时设置了 `overflow: hidden`，子元素无法越过祖先裁剪区域。

## 修复

- 礼品卡片和礼品目录面板允许菜单溢出显示。
- 打开菜单的卡片提升层级，确保菜单覆盖后续网格卡片。
- 为卡片图片单独保留左侧圆角，避免移除卡片裁剪后产生视觉回归。
- 增加桌面和 `390x844` 回归测试，验证菜单五个按钮完整渲染、菜单越过卡片底部、删除按钮可接收点击且页面无横向溢出。

## 验证结果

- `npm run lint`：通过。
- 目标单元测试：7 项通过。
- `npm run build`：通过。
- `npm audit --omit=dev --audit-level=high`：0 个漏洞。
- Playwright `admin-desktop` 与 `admin-mobile`：4 项通过。
- 真实浏览器本地生产构建：页面身份与内容正常，无框架错误；控制台 0 个错误或警告。
- 修复后菜单高度约 231px，完整越过卡片底部；卡片与礼品面板均为 `overflow: visible`，删除按钮点击命中正常，无页面级横向溢出。

## 发布与回滚

- 本次仅修改后台 CSS 与 UI 回归测试，没有 API、积分、订单、权限、数据库或 migration 变更。
- 应用和 Worker 仍通过受控生产 workflow 使用同一 release commit；发布前执行备份与健康检查。
- 若出现视觉回归，通过受控 workflow 同时回滚 App/Worker 至发布前提交，不回退数据库。
