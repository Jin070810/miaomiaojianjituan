# 成员自动清退验收

## 规则

- 仅启用中的 `MEMBER` 参与；审核员和管理员豁免，公会状态不影响资格。
- 审核通过视频以最终通过时间重置周期；默认 30 天无有效产出、剩余 7/3 天预警、清退后冷却 15 天。
- 存量成员以首次开启时间为周期起点；新成员以注册时间、审核恢复成员以批准时间为起点。
- 每位成员资格周期首次进入成员首页时展示一次规则说明；点击“我已了解”后按账号跨设备记录，不再重复弹出。
- 关闭 `MEMBER_CLEARANCE` 仅暂停执行，重新开启立即处理期间已到期成员。
- 后台“正在预警/计时”使用独立的真实聚合统计，不受成员列表展示上限影响；“已清退与冷却名单”显示最近 200 条清退记录及当前恢复状态。

## 清退与恢复

- 清退事务取消 `PENDING/APPROVED` 订单、退回锁定积分、写入清退扣减流水使余额归零、撤销 Session、停用账号并写审计；已履约订单保留。
- 冷却期满后，成员用原快手 ID 和密码提交重新加入申请；审核员或管理员批准后重新获得完整周期，驳回后 7 天可再次申请。

## Staging 验收

1. 开启开关，确认存量成员的周期从开启时刻起算，新注册成员从注册时刻起算。
2. 分别构造距截止 7、3、0 天的测试成员，确认站内通知去重、清退幂等和已清退账号无法登录。
3. 为到期成员准备余额、`PENDING/APPROVED` 订单和处理中视频，确认订单取消/库存回补、退款流水后清零、视频不再入账、Session 被撤销。
4. 冷却期结束后提交申请，分别验收批准、驳回与 7 天再次申请；批准后通过视频应重置周期。
5. 在 `390×844` 和 `1440×900` 验证首页倒计时、登录页清退状态、重新加入申请、后台审核状态、真实计时人数和已清退名单。
6. 验证首次说明包含有效产出、预警、清退权益处理、冷却与重新加入规则；关闭后仍会再显示，确认后刷新和其他设备均不再显示。

## 回滚

先关闭 `MEMBER_CLEARANCE`，再回退 Web 与 Worker 到同一已审查版本；不回退数据库、不删除资格记录、订单、积分流水或审计。错误清退使用前向修复与受审计的管理员调整，不直接删改历史。
