# 主动退团验收说明

## 范围

- 成员端“我的 → 账号 → 主动退团”提供四个固定原因：对剪辑团目前的待遇不满意、因学业等原因没有时间继续剪辑、不喜欢妙妙了、其他原因。
- 选择原因后必须进入二次确认；确认后无需审批，服务端立即执行退团。
- 退团事务会停用账号、删除全部会话、将积分余额归零、清除全部兑换订单，并终止仍在处理中的视频；未完成订单占用的礼品库存会归还。
- 退团原因、退团前积分和订单数量写入审计日志，积分清零写入独立的积分流水类型。

## 验收条件

1. 未选择原因时不能进入确认步骤；未二次确认时服务端拒绝请求。
2. 并发点击或重复请求最多完成一次退团，不能重复扣减积分或重复归还库存。
3. 成功后当前会话失效并跳转登录页；原账号不能继续登录。
4. 390×844 与 1440×900 下原因选择、确认弹窗和错误提示均无溢出或遮挡。

## 回滚

应用回滚前确认 `20260815100000_member_voluntary_exit` 已执行情况。该 migration 只新增积分枚举值，不可删除；应用回滚后不得使用新枚举写入积分流水，必要时采用前向修复。
