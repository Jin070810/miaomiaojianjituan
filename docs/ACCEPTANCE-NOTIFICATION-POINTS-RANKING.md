# 通知、批量积分与榜单结算验收说明

## PR 1

- 成员通知按用户隔离，支持全部/未读、分页、单条已读和全部已读。
- 登录会话首次加载最多弹出 10 条未读通知；关闭提醒不改变已读状态。
- 公告草稿可以全员或定向发布；发布在事务内生成通知和审计，撤回隐藏正文并关闭未读提醒。
- 视频结果、申诉、转账、兑换、发货、退款和积分变化均使用业务幂等键生成通知。

## PR 2

- 批量积分限 1–200 名有效普通成员，积分为非零整数。
- 任一成员不存在、停用或扣减余额不足时，余额、流水、通知和审计全部回滚。
- 重试使用请求幂等键，不重复增减或发送通知；后台确认摘要展示人数、每人变动、总变动量和原因。

## PR 3

- Worker 只保留视频恢复、会话清理和心跳，不自动结算榜单。
- 后台只允许结算已结束的 Asia/Shanghai 周/月周期；并发点击只能成功一次。
- 结算事务同时写入榜单快照、前五名奖励文字、全员通知和审计；无成绩周期不创建奖励。
- 前五名通知包含填写收货信息入口；收货字段复用加密档案，管理员完成发放后发送完成通知。
