# 审核员与密码找回验收记录

## 变更

- 新增 `REVIEWER`（前台名称“审核员”）角色，仅拥有密码找回申请审批权限；仍完整参与成员端的视频、积分、任务、公告、榜单与兑换。
- 密码找回申请有效期为 24 小时。审核员线下核验身份后批准或拒绝；批准会在同一事务内更新 Argon2id 密码哈希、撤销旧会话并写入审计日志。
- 新增 migration `20260729110000_reviewer_password_reset_requests`；回滚采用前向修复，不删除已经落库的审计记录或密码找回申请。

## 本地验收

- 已验证审核员登录后进入成员端而非 `/admin`，可正常打开成员首页和“我的”页面，并能进入密码协助中心。
- 已在 `390×844` 与 `1440×900` 查看找回申请与密码协助中心的空数据、加载和可操作状态。
- 已通过 `npm run db:deploy`、`npm run lint`、`npm test`、`RUN_DB_TESTS=1 npm test`、`npm run build`、`npm audit --omit=dev` 与 `docker compose config`。

## Staging 待验收

1. 将测试成员提升为审核员，确认其视频提交、积分、周任务、公告、榜单和兑换结果与普通成员一致。
2. 从登录页提交找回申请，在线下完成身份核验后由审核员批准；确认新密码可登录、旧会话已失效、审核员无法读取新密码。
3. 验证普通成员不能打开密码协助 API，审核员不能访问任意 `/api/admin/*` 接口，审核员不能审批自己、其他审核员或管理员的申请。
4. 在管理员审计日志中确认申请、批准、拒绝、过期记录以及操作者、IP、请求 ID；确认没有明文密码或密码哈希。
