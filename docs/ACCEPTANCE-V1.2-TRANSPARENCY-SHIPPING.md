# v1.2 透明化与实物发放验收

## 视频历史

- 管理员打开视频历史时，安全的快手 HTTPS 链接显示为可点击外链，使用新标签页打开，不离开后台。
- 非快手或非法历史链接只显示文本，不生成外链。
- 驳回、抓取失败和撤销记录显示结果说明；可展开查看抓取作者、提交昵称和 `photoId`。
- 搜索可以命中链接、`photoId`、抓取作者和结果说明。

## 审计日志

- 审计列表展示中文动作、中文对象和可读摘要。
- 点击一条日志可以查看操作者、角色、对象、时间、IP、请求 ID、变更前后值、原因和原始动作码。
- 手机号、地址、收款码、密码和 Session 在详情中均显示为脱敏值。
- 注册、登录成功/失败、退出、视频、积分、转账、订单、礼品和后台配置操作均能找到对应日志。

## 实物订单

- 成员兑换实物后看到“已下单，待采购”。
- 管理员驳回必须填写原因，成员看到“管理员已驳回”，积分和兑换配额恢复。
- 管理员发货时可以填写或留空快递单号；状态变为“已发货”并发送通知。
- 成员订单记录显示发货时间和快递单号（如有）。
- 管理员可以补充、修改或清除已发货订单的快递单号，每次变更都有审计记录。
- 现金礼品继续显示“待发放／已发放”，不显示物流字段。

## v1.2.1 稳定性增强

- 系统设置可切换视频提交、积分转账和礼品兑换，成员端写接口关闭后返回暂停提示，后台已有数据仍可处理。
- Worker 失败、队列滞留、Redis/Worker 不可用、对账异常和备份校验异常可通过 `ALERT_WEBHOOK_URL` 发送脱敏告警。
- 每日巡检输出积分账户、有效视频、订单、队列、Worker、Redis 和备份校验结果。
- 系统设置可下载订单、积分、视频和审计脱敏 CSV，公式单元格自动转义。
- 通知对象存在时显示“查看详情”，可跳转到对应业务记录页。
