# v1.8 成员成长与成就验收

## 范围与边界

- 成长经验为私有整数指标：每条已通过作品 `100 + floor(点赞/100) + floor(播放/1000) + 评论×5`，等级阈值为 `0/500/1500/3500/7000`。
- 本次不改变积分、审核资格、榜单、兑换和周挑战的既有权益；成长、勋章、目标、高光和复盘均只对当前会话成员返回。
- 视频抓取的标题、封面、评论数和抓取时间为可选公开元数据；抓取缺失、历史作品或解析降级都不能阻断审核、积分或重试。

## 数据库与事务验收

1. 对 staging 副本执行 `npx prisma migrate deploy`，确认 migration `20260731160000_member_growth_achievements` 成功且没有改写既有 migration。
2. 用同一成员分别验证自动通过、申诉通过和撤销：`MemberGrowthProfile`、`MemberAchievement`、`MemberMonthlyGoal` 与视频状态在同一事务内一致；重复请求不重复创建勋章或通知。
3. 验证上海时区月初边界：过去 8 周基线按 110% 锁定，新成员目标为 1 条通过作品和 100 互动值，两个指标达到后才记录完成。

5. 以两个不同成员会话请求 `GET /api/member/achievements`，确认不能看到对方勋章、目标、封面、标题或高光；未登录请求为 401。
