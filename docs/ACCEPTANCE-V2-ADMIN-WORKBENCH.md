# 管理后台运营工作台 v2 验收

## 变更边界

- 仅升级管理后台的导航、查询、数据呈现与操作确认；不改变积分、审核、兑换、榜单、周挑战或成员端规则。
- 不包含 Prisma migration。应用回退到上一 release commit 即可，历史审计数据和业务数据保持不变。

## Staging 验收

1. 以管理员登录 `/admin`，确认默认显示运营工作台；近 7 天/近 30 天切换、待办卡片、风险卡片与刷新均可用。
2. 分别进入申诉、订单、密码协助、周挑战和系统设置，确认待办卡片跳转到正确模块或安全的外部处理页。
3. 使用全局检索定位成员、`photoId`、订单号和礼品；确认搜索结果不含手机号、地址、收款码、密码或原始抓取数据。
4. 从视频和订单列表打开“操作动态”，确认审计内容已脱敏；加载失败时可关闭抽屉且不影响原列表。
5. 在 1440×900 与 390×844 验证导航、工作台、全局搜索、视频撤销、申诉处理、订单履约、空数据、加载、失败与禁用状态；确认无水平溢出。
6. 确认视频撤销、申诉通过/驳回、订单履约/驳回/退款均显示影响确认，且重复点击不会造成重复发放、扣减或退款。

## 发布门禁

- 执行仓库 `AGENTS.md` 指定的 lint、单测、数据库集成测试、构建、安全审计与 Docker 镜像校验。
- 在 staging 使用与生产同版本 Web/Worker、PostgreSQL、Redis 和脱敏生产副本完成核心流程验收；发布前创建数据库备份和服务器快照。
- 发布后检查 `/api/health`、后台工作台、待办计数、审计写入和 Worker 版本一致性；记录 release commit、操作者、时间和回滚点。
