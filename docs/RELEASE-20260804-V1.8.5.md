## 变更摘要

- 周挑战由服务端确定数值规则和整数积分，AI 只生成匿名文案；单批失败不再阻塞整周发布。
- AI 批次缩小为 8 人并增加三次重试、确定性降级、批次检查点和重启续跑。
- DeepSeek 超时拆分为总时限、首字节和流空闲时限，SSE 进度会刷新空闲计时。
- BullMQ 持久调度器固定在每周日 18:00（Asia/Shanghai），健康接口区分基础设施健康和业务降级。
- 发布镜像改为 GitHub Actions 构建并推送 GHCR；生产只按 digest 拉取和校验，不再承担 Next.js/Docker 构建负载。
