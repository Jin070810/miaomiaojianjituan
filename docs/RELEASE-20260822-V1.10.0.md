## 变更摘要

- 登录页移除公开注册入口，旧 `/api/auth/register` 固定返回 410。
- 管理员生成、停用和轮换单个高熵专属入团链接；服务端只保存 token 哈希。
- 申请阶段只保存加密手机号和 Argon2id 密码哈希，不创建 User、Session 或积分账户。
- 审核员和管理员可审核申请；批准事务创建成员、0 分账户、公会状态历史、成员资格和审计日志。
- 待审核快手 ID 大小写不敏感唯一，审核行锁和状态检查保证重复审批幂等。
- 查询凭证只保存哈希，审核列表手机号默认脱敏，申请人可查询待审核、通过或驳回原因。
