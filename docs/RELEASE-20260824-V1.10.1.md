## 变更摘要

- 修复成员端全局主题样式污染管理后台的问题，恢复管理操作按钮的可见性和一致性。
- 为高风险管理操作统一增加影响预览、关键数据复核和按风险分级的确认输入。
- 将积分管理拆分为调整、规则和流水视图；展示调整前后余额并阻止余额不足的扣分操作。
- 将生日星愿管理拆分为任务、确认、库存和记录视图，并补全更正、撤销等操作的确认说明。
- 邀请成员操作可直接定位到入团链接设置；技术错误默认收起，状态和流水代码改为面向管理员的中文文案。
- 增加独立、临时的 PR staging 门禁，使用生产模式 App/Worker、PostgreSQL 和 Redis 验证桌面端及移动端管理流程。
