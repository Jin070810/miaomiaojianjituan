## 变更摘要

- 视频抓取错误分类：链接失效等确定性失败立即驳回；超时、反爬壳页、网络抖动等瞬时失败由 BullMQ 指数退避重试，最后一次尝试仍失败才按"抓取暂时失败"驳回，成员可重新提交或申诉。
- 修复快手抓取逐 chunk 解码 UTF-8 导致中文作者名跨 64KB 边界损坏（U+FFFD）而误判"作者不一致"的问题；抖音 Chromium 崩溃后自动重建单例。
- 视频入账与申诉通过共用同一把 photoId 事务级咨询锁，杜绝同一视频两条申诉并发批准导致的重复入账。
- 周挑战生成增加迟到补跑窗口：周日晚调度缺席时，周一整天可补齐本周缺失/失败的周期并发出告警；`allowLateGeneration` 将发布截止放宽到周期开始后 24 小时。
- 成长档案并发补齐竞态修复：月度目标与勋章创建改为原生 upsert；同一事务内不再并发执行两条写语句流（避免约束冲突错误归因）。
- 依赖安全修复：next 16.3.6（critical RCE 通告 GHSA-p293-qw3h-jr36 / GHSA-2xp9-vwfh-vxw4）、sharp 0.35.5、qs 6.16.0；`npm audit --omit=dev --audit-level=high` 恢复通过。
- Worker 每分钟维护循环六个子系统隔离（Promise.allSettled），告警按任务自身来源上报；告警新增冷却窗口（默认 10 分钟，`ALERT_COOLDOWN_MS`）；停机先排空队列再清除心跳。
- 管理后台审计日志新增 `(actorId, createdAt)`、`(action, createdAt)` 索引；删除三个与唯一约束同列的冗余索引；登录与转账的快手 ID 查找优先精确匹配命中唯一索引。
- 成员端删除 unsplash 外域兜底图改用品牌占位图；通知轮询面板关闭时只刷未读角标、后台标签页暂停；积分流水标签统一并补齐 15 类流水类型。
- 部署运维：Worker 容器接入 Redis 心跳健康检查（假死由 Docker 自愈）；Web 镜像以 node 用户运行；`.gitignore` 整目录忽略产物；`.env.example` 示例密钥改为非法占位符。
- CI：e2e 改为生产构建（`next start`）运行；Docker 镜像构建启用 gha 层缓存；Nginx 增加 gzip、`server_tokens off`、http2 新语法与代理超时。
