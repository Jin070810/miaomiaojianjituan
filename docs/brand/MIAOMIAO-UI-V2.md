# 妙妙剪辑团成员端品牌规范

## 品牌定位

妙妙剪辑团是围绕妙妙直播高光共同创作的成员社区。成员把直播片段剪成短视频，在站内查看检查进度、获得积分、兑换礼物并参与榜单。

核心表达：**把直播高光，剪成你的积分。**

目标用户为 10–20 岁。文案使用短句和常用词，不用产品、技术或审核专业词。

## 妙妙角色

- 成年女性主播，黑色长直发、齐刘海，保留授权照片中的脸型、眼型和温和明亮的神态。
- 标志造型：奶油色蝴蝶结领衫、莓紫短外套、樱桃发饰、直播星光徽章。
- 风格：2D 日系贴纸、直播高光手帐、清晰轮廓、克制纸张纹理。
- 禁止：校园制服、幼儿化比例、性感化、真人照片感、图片内伪文字、第三方 Logo 和水印。
- 角色只出现在欢迎、成功、等待、空数据和错误等关键时刻；常规列表和表单保持清爽。

## 视觉资产

网页资产位于 `public/brand/miaomiao/`，只包含浏览器需要的 28 个 WebP：

- `characters/`：角色母版与 8 个动作。
- `states/`：8 个业务状态。
- `scenes/`：登录、首页、切片、礼物屋、榜单、个人中心场景。
- `patterns/`：直播灯光、弹幕星屑、时间轴、积分亮片和舞台彩带。

组件只通过 `app/member/visual-assets.ts` 使用资产，不直接散写路径。照片参考不进入仓库。

首发资产固定为 28 件：1 件角色母版、8 件动作、8 件业务状态、6 件页面场景和 5 件装饰纹理。角色与状态贴纸在 `docs/brand/sources/` 保留 2048×2048 PNG 源图，并通过纯色键控背景制作透明 WebP；页面场景保留 1536×1024 PNG 源图。4 个方向预览位于 `docs/brand/previews/`，不会被网页加载。

统一生成提示词锁定：

- `style-d` 负责角色造型，`style-a` 负责直播高光手帐环境。
- 四张授权照片只用于脸型、眼型、齐刘海和黑色长直发等身份特征，不进入 Git。
- 成年主播、自然成年比例、奶油色蝴蝶结领衫、莓紫短外套、樱桃发饰和直播星光徽章。
- 禁止可读文字、按钮、Logo、水印、校园制服、幼儿化、性感化和真人照片感。

视觉资产在 Creative Production 单一画板中完成预览、生成与登记，画板编号为 `c33a3662-c73f-4166-88b7-303132a5b337`。

## 文案原则

1. 一个提示只说一件事。
2. 按钮直接说明动作，例如“提交切片”“确认送出”“换这个礼物”。
3. 失败提示说明发生了什么和下一步怎么做。
4. 使用“正在检查”“需要看看”“补充说明”，不用“处理中”“异常”“审核队列”“申诉复查”。
5. 不制造焦虑、攀比压力或强迫兑换。

常用替换：

| 旧文案 | 新文案 |
| --- | --- |
| 我的视频 | 我的切片 |
| 提交视频 | 提交切片 |
| 积分商城 | 积分礼物屋 |
| 积分转账 | 送积分给团友 |
| 处理中 | 正在检查 |
| 异常 | 需要看看 |
| 申诉 | 补充说明 |
| 积分明细 | 积分记录 |
| 创作榜单 | 剪辑团榜单 |

## 响应式与动效

- 390px 移动端使用底部五项导航。
- 900px 及以上使用左侧导航和宽屏内容区；首页采用主内容和辅助信息双栏。
- 所有可点击控件至少 44px，焦点必须清晰可见。
- 动效只使用轻量 CSS，并在 `prefers-reduced-motion: reduce` 下关闭。
