# 妙妙剪辑团成员端 V3 原型

## 已确认方向

本组原型是成员端 UI 重构的唯一视觉依据，方向名为“妙妙直播高光手帐”。

- 妙妙 IP 是主页面的视觉焦点，但不盖住文字、按钮或数据。
- 画面使用奶油纸张、深墨标题、克制的葡萄紫和暖金色。
- 主页面有完整的品牌场景；记录页以信息阅读为主，只保留少量纸张、星星、薰衣草等装饰。
- 不继承旧版的大色块卡片、密集宫格、无效图标按钮和后台感布局。

## 排版与布局

- 展示标题优先使用开源宋体/明朝体，正文与表单使用清晰的开源黑体。
- 手机基准宽度为 `390px`，主要左右留白为 `24px`。
- 主页面首屏只安排一个 IP 焦点、一个主任务和一组关键数据。
- 列表使用细线、时间轴和留白组织，不使用层层套卡片。
- 底部导航固定五项；记录页使用返回导航，不重复显示底部导航。
- 桌面端保持相同信息层级，采用左侧导航与居中内容区，不把手机页面简单放大。

## 可用性约束

- 所有可点击区域至少 `44×44px`。
- 昵称、快手 ID、礼物名和错误信息必须支持换行或截断，不能推动右侧数据出界。
- 图标来自统一开源图标库；品牌插图和纸感装饰来自 ImageGen，不使用 CSS 图形或占位图。
- 文字、按钮、筛选和状态均为真实 HTML，不能烘焙在背景图里。
- 主操作必须有加载、成功、失败、空白和禁用状态。
- 不保留没有行为的搜索、帮助、设置、更多等按钮。

## 生成说明

原型使用内置 ImageGen 生成。所有页面均以 `02-home.png` 为身份和风格锚点，提示词固定了奶油纸感、深墨中文编辑排版、葡萄紫、暖金色、妙妙成年主播形象、直播高光手帐元素及低装饰密度。前端实现会单独生成并处理角色插图、纸张纹理和页面装饰，不直接把整张原型图当作页面背景。
